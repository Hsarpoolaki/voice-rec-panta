# آزمون صدای آفلاین فارسی پنتا

این نسخه کاملاً فارسی‌اول است و برای تشخیص گفتار از `Vosk` و برای دریافت صدا از `AudioRecord` با PCM خطی 16kHz، mono، 16-bit استفاده می‌کند. در زمان اجرا هیچ درخواست شبکه‌ای انجام نمی‌شود و `SpeechRecognizer` اندروید استفاده نشده است.

## مدل فارسی
مدل داخل خروجی نیست، چون بزرگ است و مجوز آن باید جداگانه بررسی شود. یک مدل کوچک فارسی Vosk را دانلود و extract کنید و محتوای آن را دقیقاً در مسیر زیر بگذارید:

`app/src/main/assets/model-fa`

در این نسخه پوشه می‌تواند خالی باشد، اما برنامه خطای دقیق `مدل پیدا نشد: assets/model-fa` نشان می‌دهد. مسیر جایگزین runtime، کپی مدل به `filesDir/model-fa` است. مدل باید ساختار معمول Vosk (`am`, `conf`, ... ) را داشته باشد.

زبان پیش‌فرض فقط `fa` است. placeholderهای انگلیسی و عربی در parser حفظ شده‌اند، اما مدل انگلیسی/عربی در این build bundle نشده است.

## معماری آفلاین
- `AudioCapture.kt`: lifecycle-safe، شروع/توقف و بافر PCM.
- `VoskRecognizerService.kt`: بارگذاری مدل و `Recognizer(model, 16000f)`؛ خروجی JSON و text.
- `VoiceParser.kt`: همان wake word/command parser موجود؛ wakeها شامل پنتا، پانتا، بنتا، چنتا، چندتا و Latin variants هستند.
- کنترل‌های NoiseSuppressor، AcousticEchoCanceler و AutomaticGainControl در صورت پشتیبانی فعال می‌شوند و وضعیت فعال/غیرفعال/پشتیبانی‌نشده نمایش داده می‌شود.

## تست دستی
نمونه‌ها: `پنتا طبقه ۱۰`، `پانتا منفی ۳`، `بنتا در را باز`، `چنتا چراغ روشن`، `چندتا پارکینگ ۲`، `Panta floor 12`.
محدوده طبقات عددی parser برابر `-10..45` و فرمان‌های جانبی قبلی حفظ شده‌اند.
